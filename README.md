# 地球電台 Earth Radio

可旋轉、縮放的互動地球，整合網路電台、飛機、貨船、當地時間與天氣、地震與熱帶氣旋、動態風場、公開攝影機及新聞直播。

## 啟動

1. 安裝 Node.js 22 或更新版本。
2. Windows 使用者可雙擊「啟動地球電台.cmd」，並保持命令視窗開啟。
3. 瀏覽 http://127.0.0.1:4186 。

也可在專案目錄執行 `node server.cjs`。專案已包含貨船服務的套件整合檔，直接啟動不需要安裝 node_modules。若所在目錄有中文或 OneDrive 路徑而無法啟動，請使用 Windows 啟動器。

## API 設定

貨船需要 AISStream API 金鑰；附近攝影機需要 Windy Webcams API 金鑰。啟動後可透過網頁設定，服務會儲存在後端執行目錄的 ais-config.json 與 windy-config.json。這些檔案已列入 .gitignore，請勿加入 Git 或公開分享。

Windows 啟動器將後端程式複製到使用者 Documents 下的本機執行目錄，設定檔保留在該處。網站只供本機使用，後端監聽 127.0.0.1。

## 資料與限制

資料來源包括 Radio Browser、Open-Meteo、Photon、adsb.fi、AISStream、Windy、USGS、NASA EONET 與 JTWC；第三方服務可能延遲、限流或停止提供資料。飛機動畫含位置推估，攝影機可能只提供縮時影像。颱風暴風範圍依可取得的官方風圈資料呈現，缺少資料時不自行虛構。地震、颱風與天氣畫面不作為即時警報或安全決策依據。

## 程式結構

- index.html、style.css、app.js：地球與介面
- flights.js：飛機圖層
- server.cjs：本機 HTTP 服務
- vessels.cjs、vessels-bundled.cjs：貨船服務原始碼與整合檔
- webcams.cjs：公開攝影機服務
- storm-radii.cjs：颱風風圈資料

修改前端後重新整理頁面；修改後端後重新啟動。ws 套件使用 MIT 授權，整合檔內保留其授權資訊。尚未為本專案另行指定開源授權。

## 公開網站部署（Render）

專案包含 render.yaml，可用 Render Blueprint 建立免費 Node.js Web Service。

- Build Command：`npm ci --omit=dev`
- Start Command：`npm start`
- Health Check：`/api/health`
- 環境變數 `EARTH_RADIO_PUBLIC=1`：監聽 `0.0.0.0:$PORT`，禁止所有設定寫入請求，並隱藏網頁金鑰設定。
- 選填機密環境變數：`AISSTREAM_API_KEY`、`WINDY_WEBCAMS_API_KEY`。請在主機控制台設定，不要寫入程式碼、render.yaml 或 GitHub。
- 貨船公開版共用站主指定區域，可用 `AIS_CENTER_LAT`、`AIS_CENTER_LON` 設定，預設 25、121；訪客不能修改訂閱中心。
- 未設定金鑰時，貨船和攝影機功能無法取得資料；其他不需金鑰的功能仍可使用。
- Render 免費服務閒置後可能休眠，重新開啟需等候喚醒，貨船暫存航跡也會重新累積。

GitHub 儲存庫公開程式碼與實際網站部署是分開的步驟。GitHub Pages 僅支援靜態檔案，不能執行本專案的 Node.js API。

## 海洋與氣象圖層

「海洋氣象」頁籤可獨立切換洋流箭頭、天氣圖示與溫度、NOAA/WPC 官方高低壓與鋒面。轉動或縮放後按「更新目前地球範圍」取得新的區域資料；圖層預設關閉。

洋流使用 Open-Meteo 海洋模式，顯示 m/s 流速與流去的方向，另可點選海洋查詢浪高與海溫。箭頭動畫只用於視覺辨識，不是實際時間比例；不繪製陸地取樣點。資料無法用於航海。海洋資料歸屬 Open-Meteo、Météo-France 及相關模式提供單位。

天氣圖示包含晴、雲、霧、雨、雪及雷雨，依模式天氣代碼繪製。鋒面與 H/L 來自 NOAA/NWS WPC 高解析編碼地面分析，涵蓋北美與鄰近海域；不代表全球資料，逾 24 小時即隱藏。後端會快取與限制查詢頻率。

## 東亞推估鋒面（僅實驗）

本機「海洋氣象」新增獨立開關，預設關閉。使用 Open-Meteo GFS Global 同一時次的 850 hPa 溫度、相對濕度與風場，涵蓋 15–51°N、95–155°E，3° 網格（約數百公里）。後端一小時快取，失敗後限制重試頻率。

等效位溫以簡化 Bolton 熱力公式計算；候選點要求等效位溫梯度局部極大且至少 2 K/100 km、橫跨梯度風向差至少 25°、風速至少 2 m/s，地面氣壓低於 870 hPa 的高地形遮罩排除。相鄰同類至少三點才連線，避免孤立點。冷暖類型依梯度法向風分量推估，並非鋒面實際移動速度；未經官方分析比對驗證，不等同完整的研究用 TFP 方法。

地圖與面板持續標示「模式推估／非官方分析」，以虛線及推估符號顯示。超過三小時的模式資料不繪製，沒有符合條件的線段時保持空白。不可用於判斷鋒面精確位置、預警或安全決策。

## 收音機音源偏好

電台清單和播放器會顯示 Radio Browser 提供的編碼與 kbps。預設優先選擇已載入清單中可辨識為同一電台、可由瀏覽器播放的較高位元率 HTTPS 音源；可取消偏好。電台名稱（僅移除格式與位元率註記）、國家、官方首頁需一致；缺少首頁時還需地區與近距離座標相符。不同頻道不互換，選取與收藏識別維持原電台。

音源錯誤會嘗試最多三個同台替代來源。未提供位元率時如實顯示未知；不同編碼的位元率無法直接比較音質，不會對低音質來源進行虛構升頻處理。清單快取已升版以重新取得音質欄位。

## 停下後補載附近電台

保留開啟時的全球分批載入；旋轉或縮放停止約 1.5 秒後，透過 Radio Browser 地理搜尋補載附近電台。搜尋半徑依縮放為約 1200、600 或 250 公里，每區最多查詢 1000 筆候選來源，再檢查座標、HTTPS 與可用狀態。使用 UUID 去重，保留原本搜尋、收藏與播放狀態。

同一約 2° 區域的查詢結果在記憶體快取 10 分鐘，兩次查詢至少間隔 5 秒。移動時取消過期查詢，背景分頁暫停；補載資料最多累積 6000 筆。全球載入仍在進行時，也不會覆蓋已補載電台。可在音源設定中關閉自動補載。
